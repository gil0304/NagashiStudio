# NAGASHI STUDIO

流しそうめん3Dシミュレーター — 竹・給水口・器を3D空間に配置し、水とそうめんの流れを設計して眺めるWebアプリ。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 本番ビルド (dist/)
```

## 操作

| 操作 | 方法 |
|---|---|
| パーツ配置 | 左パレットで選択 → 地面をクリック（竹の端に近づけると自動接続） |
| 配置中の回転 | `Q` / `E`（右クリックで配置終了） |
| 選択 | パーツをクリック → 右下パネルで勾配・高さ・回転を調整 |
| チェーン移動 | 起点パーツをドラッグ（開いた接続口に近づけるとスナップ接続） |
| 削除 | 選択して `Delete` |
| Undo / Redo | `⌘Z` / `⇧⌘Z` |
| カメラ | ドラッグで回転・ホイールでズーム・右ドラッグでパン |
| カメラ自由移動 | `W` `A` `S` `D` 前後左右 / `R` `F` 上下 / `Shift` 加速 |
| 水量・速度・投入 | 下部バー（そうめん / トマト / 氷 / みかん、自動投入、追跡カメラ） |
| 保存 | 自動（localStorage）。「共有URL」でコースをURLに埋め込んでコピー |

## アーキテクチャ

```
src/
├─ engine/scene.ts      レンダラー・カメラ・ライティング・夏の環境（空/雲/竹林/縁側）
├─ parts/geometry.ts    プロシージャル竹ジオメトリ（半割竹・節・支柱・器・給水桶）
├─ parts/defs.ts        パーツカタログ（竹/カーブ/Y分岐/給水口/受け鉢）と流路スプライン
├─ course/course.ts     コースグラフ（Socket接続・変換伝播・直列化・自動支柱）
├─ sim/water.ts         1D開水路ソルバー（流量・流速・水深・先端・逆勾配の滞留）
├─ sim/somen.ts         そうめん柔軟体（Verlet+距離/曲げ拘束）と食材の剛体粒子・氷の融解
├─ render/water.ts      水面リボンメッシュ＋シェーダー（Fresnel/泡/煌めき）・滝・鉢の水位
├─ render/particles.ts  飛沫パーティクル（プール式Point Sprite）
├─ editor/editor.ts     配置ゴースト・スナップ・選択・ドラッグ・スナップショットUndo
├─ ui.ts                最小UI（パレット/ツールバー/タイムライン/Inspector）
├─ audio.ts             プロシージャル音響（水音・飛沫・風鈴）
└─ main.ts              固定タイムステップループと全体の結線
```

- 水は粒子ではなく **コースグラフ上の1次元開水路モデル**（区間ごとの流量・勾配・水深）で解き、見た目は流路に沿った水面メッシュ＋シェーダーで表現。
- そうめん・食材は通常時は**流路断面に拘束**され、竹の端を越えると自由落下に切り替わる（ハイブリッド方式）。
- シミュレーションは120Hz固定ステップ、描画はrAF駆動。

## 元仕様からの主な簡略化

- クラウド保存（Supabase）→ localStorage自動保存＋URL共有
- Rapier/Worker → メインスレッドの自作Verletソルバー
- WebGPU/TSL → WebGL2＋GLSL
- 多ページ構成 → 単一ページ・最小UI
